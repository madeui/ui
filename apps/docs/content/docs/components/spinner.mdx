```tsx

```

## Sizes

The spinner is 16px (`icon.md`) by default. Pass another `icon.*` size from
`@/lib/stylex-utils` through `style` to resize it.

<Component path="spinner-sizes" />

## Composition

`Spinner` inherits `currentColor`, so it drops into any text-colored
container — a `Badge`, a line of body text, anywhere.

<Component path="spinner-composition" />

## API reference

A lucide `LoaderCircle` with a spin animation, sized 16px and colored via `currentColor` — it inherits the surrounding text color (e.g. inside a `Button`). Accepts SVG props plus a `style` prop (`StyleXStyles`, merged last).
