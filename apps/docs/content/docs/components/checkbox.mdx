## Install

```bash
npx @madeui/cli add checkbox
```

## Usage

```tsx
import { Checkbox } from '@/components/ui/checkbox';

<label>
  <Checkbox defaultChecked /> Accept terms
</label>
```

## API reference

Built on [Base UI Checkbox](https://base-ui.com/react/components/checkbox). The tables below cover the props this library adds or changes — every other prop is forwarded to the underlying Base UI part; see the [Base UI Checkbox API reference](https://base-ui.com/react/components/checkbox#api-reference) for the full list.

### Checkbox

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean` | — | Controlled checked state. |
| `defaultChecked` | `boolean` | `false` |  |
| `onCheckedChange` | `(checked: boolean) => void` | — |  |
| `indeterminate` | `boolean` | `false` |  |
| `disabled` | `boolean` | `false` |  |
| `style` | `StyleXStyles` | — | StyleX styles merged last — always win over the component's own styles. |
