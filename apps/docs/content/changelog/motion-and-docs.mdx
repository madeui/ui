A full motion audit and a major docs expansion across every component page.

- Motion tokens: three house easing curves and a duration scale replace
  ad-hoc values; every animated component respects
  `prefers-reduced-motion`
- Modal-tier surfaces (dialog, sheet) get a deliberate 200ms enter; overlay
  scrollbars fade in on hover/scroll
- ~120 new focused examples — every feature gets its own section and
  preview
- New parts for parity: Combobox chips + select-like trigger, Avatar
  badge/group, Alert and Card actions, Popover header, Select group
  labels, Button `xs`/icon sizes, Badge `ghost`
- Invalid form controls (`<Field invalid>`) now show a destructive border
  on the control itself
