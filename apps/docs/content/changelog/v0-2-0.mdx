The set grows to 54 components — including Autocomplete, Meter, Number
Field, Toolbar, and Checkbox Group — all on the same Base UI + StyleX
foundation.

- Form + Field migration to Base UI Field: labels, descriptions, and
  validation errors wire up automatically
- Colors migrated to `oklch`; accent theme support
- Guides: installation (Next.js and Vite), customization, dark mode, CLI,
  and a conventions page for AI agents
- Visual-regression harness and CI workflow
