## Install

```bash
npx shadcn@latest add @ui-lib/dialog
```

## Usage

```tsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from '@/components/ui/dialog';
```

### DialogContent

<TypeTable
  type={{
    'style': { type: 'StyleXStyles', description: "StyleX styles merged last — they always win over the component's own styles." },
  }}
/>

`DialogTrigger` / `DialogClose` accept `render` to compose with your own button: `<DialogTrigger render={<Button />}>`. `DialogOverlay`, `DialogHeader`, `DialogFooter`, `DialogTitle`, `DialogDescription` all accept `style`.

Theming note: dialogs portal to `<body>` — apply themes (e.g. `darkTheme`) to `<html>`, not a wrapper element.
