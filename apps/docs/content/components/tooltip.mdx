## Install

```bash
npx shadcn@latest add @ui-lib/tooltip
```

## Usage

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from '@/components/ui/tooltip';

// Wrap your app (or a subtree) in <TooltipProvider> once.
```

## API reference

### TooltipContent

<TypeTable
  type={{
    'side': { type: "'top' | 'right' | 'bottom' | 'left'", default: "'top'" },
    'sideOffset': { type: 'number', description: 'Distance from the trigger, in px.', default: '6' },
    'style': { type: 'StyleXStyles', description: "StyleX styles merged last — they always win over the component's own styles." },
  }}
/>

`TooltipTrigger` accepts `render` to compose with your own element: `<TooltipTrigger render={<Button />}>`.
