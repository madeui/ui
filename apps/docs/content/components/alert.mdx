## Install

```bash
npx shadcn@latest add @ui-lib/alert
```

## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from '@/components/ui/alert';

<Alert>
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>...</AlertDescription>
</Alert>
```

## Composition

```tsx
<Alert>
  <AlertTitle />
  <AlertDescription />
</Alert>
```

## API reference

### Alert

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'destructive'` | `'default'` | Visual style. |
| `style` | `StyleXStyles` | — | StyleX styles merged last — always win over the component's own styles. |

### Styling

`AlertTitle`, `AlertDescription` accept `style` (`StyleXStyles`, merged last so caller overrides always win) plus all native props of the element they render.
