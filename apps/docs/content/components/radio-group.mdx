## Install

```bash
npx shadcn@latest add @ui-lib/radio-group
```

## Usage

```tsx
import { RadioGroup, RadioGroupItem } from '@/components/ui/radio-group';

<RadioGroup defaultValue="b">
  <label><RadioGroupItem value="a" /> Option A</label>
  <label><RadioGroupItem value="b" /> Option B</label>
</RadioGroup>
```

## API reference

Built on [Base UI Radio](https://base-ui.com/react/components/radio). The tables below cover the props this library adds or changes — every other prop is forwarded to the underlying Base UI part; see the [Base UI Radio API reference](https://base-ui.com/react/components/radio#api-reference) for the full list.

### RadioGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `any` | — | Controlled selected value. |
| `defaultValue` | `any` | — |  |
| `onValueChange` | `(value: any) => void` | — |  |
| `disabled` | `boolean` | `false` |  |
| `style` | `StyleXStyles` | — | StyleX styles merged last — always win over the component's own styles. |

### RadioGroupItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` *(required)* | `any` | — | Value this item represents. |
| `disabled` | `boolean` | `false` |  |
| `style` | `StyleXStyles` | — | StyleX styles merged last — always win over the component's own styles. |
