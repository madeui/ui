<Component path="avatar-demo" />

## Install

```bash
npx shadcn@latest add @ui-lib/avatar
```

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from '@/components/ui/avatar';

<Avatar size="lg">
  <AvatarImage src="..." alt="..." />
  <AvatarFallback>MD</AvatarFallback>
</Avatar>
```

## API reference

### Avatar

<TypeTable
  type={{
    'size': { type: "'sm' | 'md' | 'lg'", default: "'md'" },
    'style': { type: 'StyleXStyles', description: "StyleX styles merged last — they always win over the component's own styles." },

/>

Always provide `AvatarFallback` for when the image fails to load.
