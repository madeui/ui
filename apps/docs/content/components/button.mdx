## Install

```bash
npx shadcn@latest add @ui-lib/button
```

## Usage

```tsx
import { Button } from '@/components/ui/button';

<Button variant="outline" size="lg">Click me</Button>
```

## API reference

### Button

<TypeTable
  type={{
    'variant': { type: "'primary' | 'secondary' | 'outline' | 'ghost' | 'destructive'", description: 'Visual style of the button.', default: "'primary'" },
    'size': { type: "'sm' | 'md' | 'lg' | 'icon'", description: 'Height and padding preset. `icon` renders a square button.', default: "'md'" },
    'disabled': { type: 'boolean', description: 'Disables interaction and dims the button.', default: 'false' },
    'style': { type: 'StyleXStyles', description: "StyleX styles merged last — they always win over the component's own styles." },
  }}
/>

All other props are forwarded to the underlying Base UI `Button` / native `<button>`.
