## Install

```bash
npx shadcn@latest add @ui-lib/dropdown-menu
```

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu';
```

## API reference

Built on [Base UI Menu](https://base-ui.com/react/components/menu). The tables below cover the props this library adds or changes — every other prop is forwarded to the underlying Base UI part; see the [Base UI Menu API reference](https://base-ui.com/react/components/menu#api-reference) for the full list.

### DropdownMenuContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `sideOffset` | `number` | `4` |  |
| `style` | `StyleXStyles` | — | StyleX styles merged last — always win over the component's own styles. |

### DropdownMenuItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | `false` |  |
| `onClick` | `(event) => void` | — | Action to run when the item is selected. |
| `style` | `StyleXStyles` | — | StyleX styles merged last — always win over the component's own styles. |

### Styling

`DropdownMenuSeparator`, `DropdownMenuLabel` accept `style` (`StyleXStyles`, merged last so caller overrides always win) plus all native props of the element they render.

`DropdownMenu` (Root), `DropdownMenuTrigger`, and `DropdownMenuGroup` are Base UI parts re-exported unstyled. Keep items inside a `DropdownMenuGroup`; Trigger accepts `render`.
