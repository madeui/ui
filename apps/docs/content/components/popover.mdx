<Component path="popover-demo" />

## Install

```bash
npx shadcn@latest add @ui-lib/popover
```

## Usage

```tsx
import { Popover, PopoverContent, PopoverTrigger } from '@/components/ui/popover';
```

## API reference

### PopoverContent

<TypeTable
  type={{
    'side': { type: "'top' | 'right' | 'bottom' | 'left'", default: "'bottom'" },

    'sideOffset': { type: 'number', default: '6' },

`Popover` (Root) accepts `open` / `defaultOpen` / `onOpenChange`; `PopoverTrigger` accepts `render`.
