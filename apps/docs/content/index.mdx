An open-source UI library following the shadcn code-ownership model — components
are copied into your project as editable source — built on Base UI (headless
behavior and accessibility) and StyleX (compile-time atomic CSS).

## Install

```bash
npx shadcn@latest add @ui-lib/button
```

## Guides

- [Installation](/installation) — StyleX build setup for Next.js and Vite,
  first components.
- [Customization](/customization) — tokens, themes, the `style` prop, and
  editing component source.
- [Dark mode](/dark-mode) — apply the dark theme without a flash.
- [CLI](/cli) — `ui-lib init`, `add`, `list`.
- [For AI agents](/agents) — the conventions agents rely on.
